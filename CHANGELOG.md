# Changelog

## 1.0.1

- Form fields with Turkish letters such as ş, ğ and ı now preview at the right size, in the same font the saved file uses. Before, the preview switched to an oversized fallback font (the saved file was already correct).
- Fields that stay fillable after saving embed the complete font, so other programs can type any letter into them later.
- The text box no longer hides the first letter while you type.
- README demos for English and Turkish.

## 1.0.0

First release, in the browser and as a Windows app.

- Text anywhere on a page: three IBM Plex families, bold, any size and colour, several lines, full Latin, Turkish and Cyrillic support; added text stays searchable.
- Form filling for text fields, tick boxes, option groups, drop-downs and lists, with a live preview on the page. Fields stay fillable when the original file is saved; otherwise they are written into the page.
- Signatures: draw, type in a handwriting font or upload a photo with the background removed; remembered on the device.
- Highlighter, rectangle, freehand pen, white-out, tick, cross, dot, today’s date and pictures (also pasted from the clipboard).
- Select, move, resize, nudge, duplicate, bring to front, delete; undo and redo for every change.
- Page list with multi-select and drag-and-drop; rotate, duplicate, delete and insert blank pages.
- Merge PDFs and images into one document; images become pages.
- Save the whole document, the selected pages, every page as its own PDF in a ZIP, or every page as a PNG.
- Page numbers, text watermark and document details.
- Password-protected PDFs open with their password; encrypted files that cannot be rewritten are saved as images.
- Works offline and can be installed from the browser; English and Turkish; light and dark themes.
- Windows app: portable and installer builds, Open with for PDF files, the system Save dialog, and a daily check for new releases.
